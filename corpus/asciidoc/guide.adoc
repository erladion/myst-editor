[[requirements]]
== Requirements

Before you start, make sure you have:

* A supported operating system
* At least 2 GB of _free_ disk space
** More if you install the examples
* An internet connection
+
Without one, use the offline installer.

NOTE: The installer checks these for you.

.Supported versions
[options="header"]
|===
| System | Version
| Linux | 6.0 or later
| macOS | 14 or later
|===

== Installing

. Download the installer from https://example.org/download[the download page].
. Run it:
+
[source,bash]
----
./install.sh --prefix /opt/widget
----
. Check that it worked with `widget --version`.

[TIP]
====
You can also install with your package manager.

See <<requirements>> for what it needs.
====

[WARNING]
.Older systems
Don't use version 1.x installers on new systems.
