# Getting started

Welcome to the **Widget** documentation. This guide covers *installation*,
configuration, and your first project. See [the website](https://example.com)
for news, or read the `README` file.

## Installation

Install the package with pip:

```bash
pip install widget
```

Then verify it works:

1. Open a terminal.
2. Run `widget --version`.
3. Check that the output matches the release notes.
